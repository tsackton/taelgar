Taelgar Git secret filter
=========================

Purpose
-------

Markdown notes may contain raw DM-only fragments. Git stores deterministic
placeholders while the authorized working copy stores the original fragments
under .secrets-v2. The previous numeric placeholders and flat .secrets files
remain readable for recovery.

Safety properties
-----------------

* The implementation and hooks are tracked in _scripts.
* A path-specific include in the user's global Git configuration survives
  recreation of this repository's .git directory.
* The filter is required, so a missing or failing implementation stops Git.
* Pre-commit and pre-push hooks independently reject raw secret syntax.
* Recovery sidecars use the note's full repository path, are written
  atomically, and are restricted to the current user.
* Unclosed or overlapping markers fail closed.
* A repository workflow checks both the tests and the committed tree.

Activation
----------

Run:

    python3 _scripts/install_secret_filter.py

Then verify at any time with:

    python3 _scripts/install_secret_filter.py --check

Before replacing history or changing branches, snapshot all currently visible
DM fragments into the v2 recovery store:

    python3 _scripts/secret_filter.py snapshot-working-tree

The installer should be activated only after a history-cleanup dry run has
been verified, so the current exposed Git tree does not create a misleading
working-tree-wide diff.
