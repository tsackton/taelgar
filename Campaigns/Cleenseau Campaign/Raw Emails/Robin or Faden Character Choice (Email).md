I think both Faden and Robin would end up with starting equipment that was
somewhat driven by their backstory.

For Robin, I think the backstory is very similar to what I previously
wrote. However, I think I'd set it up so that Robin found the Lantern of
the Bright Hearth as the precipitating event for leaving the Tyrwinghan
marches - and he would have left seeking more information about this
person. So the game would start with Robin seeking someone/details about
someone driven by the Lantern. If you like that I can write up something
more specific.

create him still works, same with the old email for background.. But

specific in mind.
