Random Thoughts on Taelgar:

We need to determine which names are our own and which have been stolen from other worlds/ books, in order that for our final version we aren't running into copywrite stuff.

In the meantime, we need to make/ find developed sections on:

- The astral plane- rules description, functional uses
- True magic- rules, function
- Various races- packages, personality traits, where are they
- Kenku (well, same as the rest of the races)
- Rangers- who, what, where
- Personalities- kings, dragons, etc.
- Marsember
- Chardon
- Rohan- roharic society, the king's horse
- Points of Interest- the temple
- Ages- dragon warefare, ending an age
- Eru/ Melkor- Aspects, religion
- The Dreamworld- how it works, rules, functional uses
- Governments
- Trade
- A set distance scale for the map, as nice as "one week's travel= one hand" is, we need something more exact.
- Mockers

Please add to the list, or perhaps specify subtopics under the topics I have listed. I'm anxious to hear y'all's thoughts.

Good call for web site links (though I doubt Nick's Place has a page). Maybe I'll learn how to author web sites and give mike a hand. Maybe I'll be lazy. Whatever the case.
