# Early Taelgar Price List

## Coinage

### Sembara

200 Sembian copper (cp) = 20 Sembian commons = 1 Sembian noble

| Coin | Value | Description |
| --- | ---: | --- |
| Copper | $1 | Small, about the size of a dime; 1,000 to a pound; made of copper |
| Common | $10 | Small, about two-thirds the size of a dime; 1,350 to a pound; made of silver |
| Noble | $200 | About the size of an English pound; 200(?) to a pound; made of gold |

### Chardon

200 Chardon pennies = 20 Chardon marks = 1 Chardon crown

| Coin | Value | Description |
| --- | ---: | --- |
| Penny | $0.50 | About the size of a quarter; made of copper; 800 or so to a pound |
| Mark | $5 | About 150% the size of a dime; 900 or so to a pound; made of silver |
| Crown | $100 | About the size of a $0.50 piece; 500(?) to a pound; made of gold |

Exchange rates are primarily unimportant, as most merchants will accept either type of coinage. There are half and quarter versions of the penny and copper.
